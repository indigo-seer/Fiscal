# Fiscal

Fiscal is a private, local-only iOS expense tracker built with SwiftUI. Expenses and categories remain on the device. The repository contains both the app and its WidgetKit quick-add extension.

## Project layout

- `Fiscal/Sources/Fiscal`: main iOS app
- `Fiscal/Sources/FiscalWidget`: WidgetKit extension
- `Fiscal/project.yml`: native Xcode project specification
- `Fiscal/Package.swift` and `Fiscal/xtool.yml`: optional local xtool build
- `.github/workflows/build-signed-ipa.yml`: signed IPA build

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen), so generated `.xcodeproj` files are intentionally ignored.

## Configure signed GitHub builds

Create these identifiers and provisioning profiles in the Apple Developer portal:

- App: `com.aadya.Fiscal`
- Widget: `com.aadya.Fiscal.FiscalWidget`

The widget needs its own provisioning profile. For an IPA that installs directly on registered devices, use Apple Development signing and development profiles. For broader registered-device distribution, use Apple Distribution signing and ad hoc profiles.

Add these repository secrets under **Settings → Secrets and variables → Actions**:

- `APPLE_TEAM_ID`: Apple Developer Team ID
- `BUILD_CERTIFICATE_BASE64`: base64-encoded `.p12` signing certificate
- `P12_PASSWORD`: password used when exporting the `.p12`
- `APP_PROVISION_PROFILE_BASE64`: base64-encoded app provisioning profile
- `WIDGET_PROVISION_PROFILE_BASE64`: base64-encoded widget provisioning profile
- `KEYCHAIN_PASSWORD`: a random temporary CI keychain password

Optional repository variable:

- `CODE_SIGN_IDENTITY`: defaults to `Apple Development`; use `Apple Distribution` with distribution profiles

On macOS, encode signing files without line wrapping:

```sh
base64 -i FiscalSigning.p12 | pbcopy
base64 -i Fiscal.mobileprovision | pbcopy
base64 -i FiscalWidget.mobileprovision | pbcopy
```

Run **Actions → Build signed Fiscal IPA → Run workflow** and choose the matching export method:

- `debugging`: development profiles
- `release-testing`: ad hoc distribution profiles
- `app-store-connect`: App Store profiles

The signed `Fiscal.ipa` is available in the workflow run’s Artifacts section for 14 days.

## Generate the project locally on a Mac

```sh
brew install xcodegen
cd Fiscal
xcodegen generate
open Fiscal.xcodeproj
```

Xcode performs the official App Intents metadata extraction and builds the WidgetKit extension as part of the Fiscal app archive.
